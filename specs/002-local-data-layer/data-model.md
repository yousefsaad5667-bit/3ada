# Data Model: Local Data Layer

**Phase**: 1 — Design & Contracts
**Feature**: `002-local-data-layer`
**Date**: 2026-07-04

## Entities

---

### 1. RelapseRecord

Represents a single relapse event logged by the user.

| Field | Type | Required | Validation | Notes |
|---|---|---|---|---|
| `id` | `string` (UUID v4) | ✅ Yes | Immutable after creation; generated by `crypto.randomUUID()` | Primary key |
| `date` | `string` (ISO 8601 date: `YYYY-MM-DD`) | ✅ Yes | Must be a valid calendar date; not in the future | Day-level granularity |
| `time` | `string` (`HH:MM` 24h) | No | If present, must be `00:00`–`23:59` | Optional time of occurrence |
| `ampm` | `'am' \| 'pm' \| null` | No | Only meaningful when `time` is present | Display hint for 12h format |
| `count` | `number` (positive integer) | ✅ Yes | Integer ≥ 1 | Number of occurrences in this record |
| `urgeLevel` | `number` (integer 1–10) | No | If present, must be integer in [1, 10] | Craving intensity at time of relapse |
| `reason` | `string` | No | Max 500 characters | Free-text trigger/reason |
| `notes` | `string` | No | Max 1000 characters | Free-text additional notes |
| `createdAt` | `string` (ISO 8601 datetime) | ✅ Yes | Immutable after creation; set at record creation | Audit timestamp |
| `updatedAt` | `string` (ISO 8601 datetime) | ✅ Yes | Updated on every successful edit | Audit timestamp |

**Storage Key**: `habit-tracker-relapse-records`
**Storage Format**: `RelapseRecord[]` (JSON array)
**Default Value**: `[]` (empty array when no data exists)

---

### 2. Settings

Application-wide user preferences. Only one Settings object ever exists per installation.

| Field | Type | Required | Validation | Notes |
|---|---|---|---|---|
| `theme` | `'dark' \| 'light'` | ✅ Yes | Must be one of the two literal values | Consumed by `ThemeService` |
| `language` | `'ar'` | ✅ Yes | Only `'ar'` is valid in v1 | Reserved for future l10n support |
| `defaultUrgeLevel` | `number` (integer 1–10) | No | If present, integer in [1, 10] | Pre-fills urge level in the record form |

**Storage Key**: `habit-tracker-settings`
**Storage Format**: `Settings` (JSON object)
**Default Value**:
```json
{ "theme": "dark", "language": "ar", "defaultUrgeLevel": null }
```

---

### 3. DashboardPreferences

User's saved layout choices for the dashboard. One object per installation.

| Field | Type | Required | Validation | Notes |
|---|---|---|---|---|
| `cardOrder` | `string[]` | ✅ Yes | Array of non-empty strings; no duplicates | Ordered list of dashboard card IDs |
| `hiddenCards` | `string[]` | ✅ Yes | Array of non-empty strings; subset of known card IDs | Cards the user has dismissed |

**Storage Key**: `habit-tracker-dashboard-prefs`
**Storage Format**: `DashboardPreferences` (JSON object)
**Default Value**:
```json
{ "cardOrder": [], "hiddenCards": [] }
```

---

### 4. StorageVersion

Metadata record for schema migration coordination. Stored as a single integer, not an object.

| Field | Type | Notes |
|---|---|---|
| `version` | `number` (positive integer) | Current schema version; `1` is the initial baseline |

**Storage Key**: `habit-tracker-schema-version`
**Storage Format**: `number` (JSON number)
**Default Value**: `0` (interpreted as "no versioned schema yet" — triggers v0 → v1 migration)
**Current Version**: `1`

---

### 5. ExportBundle

The envelope structure written to the backup JSON file. Not stored in `localStorage` — only used for file I/O.

| Field | Type | Required | Notes |
|---|---|---|---|
| `schemaVersion` | `number` | ✅ Yes | Must match `CURRENT_SCHEMA_VERSION` or be ≤ it |
| `exportedAt` | `string` (ISO 8601 datetime) | ✅ Yes | Timestamp when export was triggered |
| `relapseRecords` | `RelapseRecord[]` | ✅ Yes | Full array; may be empty |
| `settings` | `Settings` | ✅ Yes | Full settings object |
| `dashboardPreferences` | `DashboardPreferences` | ✅ Yes | Full preferences object |

---

### 6. ValidationResult\<T\>

Generic return type used by all validator functions. Not stored anywhere — used only at runtime.

| Field | Type | Notes |
|---|---|---|
| `valid` | `boolean` | `true` if the input passed all validation rules |
| `value` | `T \| null` | Populated (non-null) only when `valid === true` |
| `errors` | `ValidationError[]` | Empty array when `valid === true`; populated otherwise |

---

### 7. ValidationError

A single field-level validation failure message.

| Field | Type | Notes |
|---|---|---|
| `field` | `string` | The field name that failed (e.g., `'date'`, `'urgeLevel'`) |
| `messageAr` | `string` | Arabic-language error message for display (FR-009) |

---

### 8. ImportStrategy

Union type representing the two supported import behaviors.

```typescript
type ImportStrategy = 'replace' | 'merge';
```

| Value | Behavior |
|---|---|
| `'replace'` | All existing local data is deleted and replaced with the file contents |
| `'merge'` | Records from the file are added; ID conflicts favor the existing local record |

## Validation Rules (Full Reference)

### RelapseRecord Validation

| Rule | Arabic Error Message |
|---|---|
| `date` is missing or empty | `حقل التاريخ مطلوب.` |
| `date` is not a valid calendar date | `التاريخ غير صالح.` |
| `count` is missing | `حقل العدد مطلوب.` |
| `count` is not a positive integer | `العدد يجب أن يكون رقماً صحيحاً موجباً.` |
| `urgeLevel` is present but < 1 or > 10 | `مستوى الرغبة يجب أن يكون بين 1 و10.` |
| `urgeLevel` is present but not an integer | `مستوى الرغبة يجب أن يكون رقماً صحيحاً.` |
| `time` is present but not in `HH:MM` format | `صيغة الوقت غير صالحة.` |
| `reason` exceeds 500 characters | `السبب يجب ألا يتجاوز 500 حرف.` |
| `notes` exceeds 1000 characters | `الملاحظات يجب ألا تتجاوز 1000 حرف.` |

### Settings Validation

| Rule | Arabic Error Message |
|---|---|
| `theme` is missing or not `'dark'`/`'light'` | `قيمة السمة غير صالحة.` |
| `language` is missing or not `'ar'` | `قيمة اللغة غير صالحة.` |
| `defaultUrgeLevel` is present and not integer in [1, 10] | `مستوى الرغبة الافتراضي يجب أن يكون بين 1 و10.` |

### ExportBundle Validation (for Import)

| Rule | Arabic Error Message |
|---|---|
| JSON is unparseable | `ملف الاستيراد غير صالح أو تالف.` |
| `schemaVersion` field is missing | `إصدار المخطط مفقود في الملف.` |
| `schemaVersion` is higher than `CURRENT_SCHEMA_VERSION` | `إصدار المخطط غير مدعوم. يرجى تحديث التطبيق.` |
| `relapseRecords` is not an array | `بيانات السجلات غير صالحة في الملف.` |
| `settings` is missing or not an object | `بيانات الإعدادات غير صالحة في الملف.` |
| `dashboardPreferences` is missing or not an object | `بيانات التفضيلات غير صالحة في الملف.` |

|---|---|---|

## Entity Relationships

```
Settings (1) ─────────────────── (1) Installation
DashboardPreferences (1) ──────── (1) Installation
RelapseRecord (0..*) ──────────── (1) Installation

ExportBundle (aggregates all three domain entities for file I/O)
```

There are no foreign key relationships between domain entities. Each entity is stored and retrieved independently. The only coupling is in `ExportBundle` which collects all three for backup/restore.
